# Категории и места хранения

| Код категории | Название |
|---|---|
| dairy | Молочные продукты |
| vegetables | Овощи |
| fruit | Фрукты |
| meat | Мясо |
| groceries | Бакалея |
| other | Прочее |

Места хранения: `fridge` — холодильник, `freezer` — морозильник,
`cupboard` — шкаф. Допустимые единицы: `pcs`, `g`, `kg`, `ml`, `l`.
Место хранения не меняет введённую дату годности автоматически.
